# Direct Role Routing Validation

The direct Farmer/FPO destination at `#marketplace-farmer` opens the existing Farmer dashboard immediately. The marketplace landing hero and role-picker are absent; the first visible workspace content is the Farmer/FPO dashboard.

The direct Buyer destination at `#marketplace-buy` opens the existing Buyer dashboard immediately. The marketplace landing hero and role-picker are absent; the first visible workspace content is the Buyer dashboard.

The direct Admin destination at `#marketplace-admin` opens the existing Admin dashboard immediately. The marketplace landing hero and role-picker are absent; the first visible workspace content is the Admin overview.
